## Viewing the Code

actionlib_tutorials is a series of tutorials for using the
[actionlib](actionlib) client API. You can browse these tutorials by
installing [common_tutorials](common_tutorials) and `roscd`-ing to the
`actionlib_tutorials` package, i.e. 

```
$ apt-get install ros-$ROS_DISTRO-common-tutorials
$ roscd actionlib_tutorials
```
